# Poker Web Scraper

## Описание проекта

Данный проект представляет собой веб-скрапер на языке Python для автоматического сбора информации о покерных комбинациях.

Программа получает данные с сайта https://hands.poker/ и сохраняет их в CSV-файл.

## Собираемые данные

- Ранг покерной комбинации
- Название комбинации
- Пример комбинации
- Вероятность получения комбинации

## Используемые технологии

- Python
- Requests
- BeautifulSoup
- CSV

## Как запустить проект

1. Установить Python.
2. Установить библиотеки командой `pip install -r requirements.txt`.
3. Запустить программу командой `python scraper.py`.
4. Открыть созданный файл `poker_hands.csv`.

## Результат

Программа автоматически собирает информацию о покерных комбинациях и сохраняет её в таблицу для дальнейшего анализа.
